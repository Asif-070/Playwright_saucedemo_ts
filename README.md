# Playwright Automation Project

This is a Playwright automation project for testing the SauceDemo website using TypeScript. It includes end-to-end test scenarios covering login, inventory, and checkout flows.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Install Playwright browsers:
   ```bash
   npx playwright install
   ```
3. Run the tests:
   ```bash
   npx playwright test
   ```

## Project Structure

- `pages/` — Page object classes for different pages
- `tests/` — Automation test cases
- `playwright.config.ts` — Playwright configuration

## Helpful Command

To view the HTML test report:
```bash
npx playwright show-report
```
